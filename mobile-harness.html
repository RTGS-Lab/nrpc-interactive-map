Phone harness — 390 × 844

The frame is an iPhone 14 viewport. Media queries inside it match a phone's, so js/mobile.js turns itself on the same way it does on a device.

Geolocation is a secure-context API: over http://localhost it works, over http://<LAN-IP> it does not. For a real device use ./serve-mobile.sh.

To drive it without touching the browser's permission dialog, mock the API in the frame from the DevTools console:

const w = document.getElementById('app').contentWindow;
w.navigator.geolocation = {
  getCurrentPosition: (ok) => ok({
    coords: { latitude: 45.10519, longitude: -93.28234, accuracy: 12 },
    timestamp: Date.now()
  }),
  watchPosition: () => 1,
  clearWatch: () => {}
};

Then tap Use my location. Two parcels worth testing: 45.10519, -93.28234 (Brooklyn Park) and the Golden Valley parcel 1802924440108.
